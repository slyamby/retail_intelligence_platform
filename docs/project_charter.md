# Project Charter

## Project Name
Retail Intelligence Platform

## Client
BrightMart Retail Ltd

## Business Problem

BrightMart receives monthly sales data from 15 branches.
The finance team spends approximately two days every month
combining, cleaning and preparing reports.

The process is manual, error-prone and difficult to scale.

## Project Goal

Build an automated reporting system that:

- Imports monthly branch data
- Cleans and validates records
- Produces management dashboards
- Forecasts future sales
- Reduces reporting time significantly

## Success Criteria

- Reporting time reduced from two days to less than one hour
- Duplicate records eliminated
- Interactive dashboards available
- Monthly forecasting implemented

## Deliverables

- Python Cleaning Pipeline
- Power Query Automation
- Excel Dashboard
- Power BI Dashboard
- Machine Learning Model
- Streamlit Web Application
